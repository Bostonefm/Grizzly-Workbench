## Updates and changelog

Open **Help → Updates & changelog**, or select the version in the title bar. Installer builds check the official GitHub release channel at startup and every six hours. Background downloads are enabled by default and can be disabled in the app.

Updates wait for **Install and restart**. Unsaved work blocks installation; normal quit does not install an update. Files, history and preferences remain on your PC. ZIP users update manually until they install Setup.

## Included tools

- Tabbed editing, syntax highlighting, search and replace, folding, undo and redo.
- Side-by-side comparison with a second local file, last save, disk version or local snapshot.
- Previewed, undoable JSON/JSONC punctuation repairs and missing final XML closing tags; saving remains explicit.
- Located diagnostics for supported formats and selected game settings, original starter templates and local file history.

Validation covers supported syntax and selected game rules. Real game/server behavior still requires testing. Workbench does not require a Nexus account, database connection or subscription, and does not upload your editing documents.

## Alpha status

Version 0.1.0-alpha.3 is an **unsigned development alpha**. Windows may show an unknown-publisher or reputation warning. The release includes SHA-256 checksums; these do not establish a trusted Windows publisher.

Native Windows acceptance covered actual NSIS installation, invalid-checksum rejection, download retry, unsaved-work protection, update/restart and preservation of local files and settings.

This repository hosts official release downloads and update metadata. Application source publication and licensing are separate decisions.
